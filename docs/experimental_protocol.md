# 实验审计与归因计划（2026-10-28）

本阶段只修复实验的可复现性、诊断能力与可归因性，不新增病史压缩、窗口或分层结构。已完成的探索性实验冻结，当前提交预测不变。

## 固定锚点

- 强基线：`artifacts/optimization/runs/no-pretrain-l512-seed{17,42,73}`。旧 `TimelineTransformer`、同一官方患者划分、同一 `prepared_l512`、BOS+最近511事件、位置容量1024、无预训练。
- 三种子全部保留：17/42/73。输入、标签、既往疾病屏蔽、词表、数值分箱、静态特征、患者顺序逐项固定并记录SHA256。
- 主选模指标保持总体验证mAP；长史133人/短史232人仅作固定分组评价，不事后改checkpoint选择规则。
- 主比较为每个种子的单模型指标，再对种子求均值和样本标准差。患者bootstrap同时应用于所有模型与种子，不平均概率、不挑种子。
- 同时报告macro-AUROC、micro-AP、Brier与at-risk BCE。mAP降低不能直接称为模型所有能力变差。

## 门槛A：重载与训练闭环

1. 三份旧checkpoint分别重载，验证患者/CODE顺序、先验屏蔽和预测；概率最大绝对误差不超过1e-6，重算mAP与保存值一致。概率舍入导致的并列须单独解释。
2. 用当前训练器先重跑seed17，语义训练配置完全不变；新增的仅为诊断日志。记录初始化状态指纹、每轮患者顺序指纹、梯度裁剪前范数、裁剪比例、AMP跳步及eval模式训练集指标。
3. 旧CUDA使用warn-only非确定性算法，同种子不承诺逐位重训。预先定义复现警戒：最佳mAP差超过0.002，或固定epoch曲线偏差超过0.005时，先停止后续归因并定位来源；这些是审计报警阈值，不是统计显著性门槛。允许范围内的偏差也完整报告，不称为逐位复现。
4. seed17通过后补齐seed42/73。若需要切换严格确定性设置，锚点和全部对照一起切换，并把它记录为新的实验条件，不能混用。

## 门槛B：无需训练的等价性检查

- 旧模型保留BOS、因果attention、位置容量1024、旧读出，只适配2D输入到3D单事件袋；logits、loss、梯度和单步AdamW结果应一致。
- 位置容量降至512时，复制有效位置行和其它权重；对不超过512位置的输入验证数学前向等价，不把额外未用位置行算成实际表达容量。
- 计数常量、移除BOS/位置整体位移均不进入最小归因实验。常量可被偏置吸收不代表AdamW训练参数化等价。
- 总参数、监督梯度覆盖的参数张量、可达位置行分别记录；无预训练时未使用的language head不能被计为实际监督容量。

## 门槛C：最小2×2归因

输入与共同backbone初始化、训练设置保持锚点条件。四个单元是：

1. `C0R0`：因果attention + 原last/static/dropout/Linear读出（锚点）。
2. `C1R0`：仅改双向attention。
3. `C0R1`：仅改为临床状态mean+last/static/MLP读出包。
4. `C1R1`：两项共同改变。

新读出只用独立的初始化RNG，不改变共同backbone或训练开始时的全局RNG；读出内部的dropout形状仍可能改变后续随机轨迹，不能声称训练路径逐位相同。新读出包的参数增量明确报告，不把结果解释成某一个内部组件的独立作用。

分别计算attention主效应、读出主效应与交互作用；若交互明显，不能把一次串行bridge的差值当成可独立相加的贡献。每格均跑完整三种子，上限35epoch、patience8、batch16、AdamW lr3e-4/wd0.01、dropout0.15、同AMP设置。

仅当该2×2对读出包给出明确、一致的退步证据，下一阶段才拆pooling与MLP；当前阶段不提前新增那些模型。区间宽或种子方向不一致时，结论写“尚未识别”，不继续搜索直到找到高分。

## 训练与泛化诊断

- 每轮eval模式计算训练集和验证集BCE/mAP/Brier；在线训练BCE含dropout且跨参数更新平均，不能直接作为最终模型的拟合能力。
- 梯度和AMP诊断检查数值优化是否异常；必要时再做固定小训练子集记忆测试。小子集的全40类mAP上限可能不足1，必须同时检查有阳性类别AP和BCE。
- 按病种分解差值，显式记录小阳性数及相关病种共用患者。初步审计显示新raw的mAP更低但Brier/BCE与micro-AP更好；约60%的净mAP下降来自仅10名阳性患者覆盖的三个肺癌相关目标，不能推断所有病种全面退化。
- 现有记录支持过拟合迹象；尚未证明学习率错误、静态特征失效、均值压缩是主因或分层思想失败。

交付冻结清单、重载/重训报告、等价性检查、2×2结果与带证据级别的原因分析。保持官方split，不使用外部数据或权重，不在验证集上反传，不使用隐藏测试结果选方案。所有推断仍以已经反复使用的验证集为条件，不能当作无偏测试泛化结论。
