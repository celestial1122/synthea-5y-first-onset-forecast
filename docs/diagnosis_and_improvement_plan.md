## 0. 一页结论

| 事实 | 数字 |
| --- | --- |
| Codex 当前单模型 Transformer（严格 C0R0，3 种子） | val mAP 0.2209 ± 0.0123 |
| Codex 提交的 6 成员集成 | val mAP 0.2677 |
| 只用 **年龄+性别** 的逻辑回归 | 0.1229 |
| 手工计数特征 + **LightGBM 单模型**（无调参，特征 3 秒） | **0.2565** |
| Transformer 3 种子概率平均 | 0.2543 |
| GBM + Transformer 50/50 融合（**val 上**） | 0.2773（§7.3 证明这是 val 选择造成的假象） |
| GBM 在 train 上 5 折 OOF（2791 人，噪声更小） | 0.2104–0.2141 |
| Transformer（multi_wide）5 折 OOF | **0.1751**（val 0.249） |
| OOF 上选权重的最终融合（0.9 表格 + 0.1 Transformer） | OOF 0.2147 / val 0.2564 |
| 同一批 CV 模型在 val 子集 vs train 子集上的 OOF mAP | 0.244 vs 0.209（**val 偏容易 ~0.035**） |

核心判断：

1. **Codex 没抓住的关键不是模型结构、确定性或损失函数，而是任务的生成过程**。40 个目标分成三类，性质完全不同：15 类"无记忆意外事件"（任何模型 AP≈0.10，天花板）；10 类"死亡对齐"的终末事件（标签本质是"5 年内死不死、死于什么"，占现有 mAP 的一半）；15 类 Synthea 模块链条（信息在历史里，树模型能读、Transformer 读不好）。
2. **Codex 所有实验的效应量都在噪声以内**。365 个验证人、每类中位 11 个阳性，单类 AP 的抽样 SD≈0.1，mAP 的 bootstrap SD≈0.013，种子 SD≈0.01；他比较的 attention 方向（−0.017）、读出（−0.011）、ranking loss（+0.0001）都分不出来。此外 val 本身比 train 偏容易 ~0.035，所有 val 上的数字都偏乐观。
3. **能立即落地、有证据的改进**：(a) 把模型选择搬到 train 的 5 折 OOF（这一步本身改变了后面所有结论）；(b) 计数特征 GBM 作为主模型（OOF 0.214 vs Transformer 折模型 0.175）；(c) GBM 与 Transformer 融合在 val 上看似 +0.03，**在 OOF 上只有 +0.0006**，最优权重 0.9 在表格侧——val 上的融合增益是 val 偏易 + 早停选择 + 权重选择三重乐观的产物（§7.3）；(d) Transformer 侧的 wide 计数通路 / 多任务头、门控×病因两阶段、竞争风险 softmax 在 OOF 上都不超过直接 GBM。
4. **两个被证伪的"直觉方案"**：每个时间步都打标签的密集监督（0.178 vs 0.210，更差）和多 landmark 数据增强（GBM 0.252 vs 0.257，无收益）。原因是第 2 点：官方窗口是"记录末 5 年"，不是随机 5 年窗口，分布不同。
5. **必须在报告里披露的 artifact**：43% 的 train/val 患者在窗口内死亡，anchor 由"末次就诊−5 年"定义，死亡从 anchor 前历史即可以 AUROC 0.96–0.98 预测出来（通过日历年代代理：QALY/DALY 观测只存在于 2011 年后、流感疫苗编码、wellness 就诊间隔等）。测试集按同样方式构造，所有模型（包括 Codex 的）都在隐式利用它。
6. **第六轮（§10.3）把“低”定位清楚了**：意外 15 类是硬天花板（AP≈流行率，学习曲线平坦）；链条 15 类与终末 10 类**不是信息上限而是样本受限**——训练患者从 25% 到 100% 时 OOF 仍以每 e 倍 +0.03（终末 +0.07）线性上涨，装配相对单模型的 +0.028 等价于 2.4 倍数据；死亡不是缺失信息（真值 oracle 仅 +0.002）；合法且成立的只有样本效率手段（person-period、交叉拟合装配、逐目标特征筛选），死亡门控混合等结构化方案为负。
7. **第七轮（§10.4）按 README 许可加入 genomics / imaging**：README 写明 “You may use any modality provided (structured CSV, imaging, genomics)”；数据审计（`docs/data_audit.md` §5）证明这些文件是 Coherent 按一生诊断（含 anchor 后）反向生成的标签派生信号，第 1–6 轮主提交不用。用户决定使用后，最终提交 `predictions.csv` 交叉拟合 OOF **0.2671** / val **0.3158** / AUROC 0.7860（对比干净版 0.2381 / 0.2832 / 0.7771），增益几乎全部来自中风（0.235 → 0.831）、冠心病、步态异常 / 脑微出血、心梗、骨质疏松。报告必须披露这一生成机制。
8. **第八轮（§10.5）把数据用对**：特征分组地图显示信号在低维稠密字段（年龄 / 年代、P(死亡)、基因组剂量、费用）而非事件顺序；`patients.csv` 的终生费用两列不是事件表之和（表内费用仅占 0.5%–17%），做两阶段残差后对癌症目标是干净的窗口治疗信号，且费用信号强烈依赖生死（中风生者 0.91 / 死者 0.71）。用户决定使用后，最终提交 `predictions.csv` 交叉拟合 OOF **0.3157** / val **0.3676** / AUROC 0.7869：链条 0.224 → 0.309、终末 0.460 → 0.643、意外不动。无历史的“年龄 + prior + 基因组 + 费用”模型单独 0.2595，高于第六轮全部历史 token 的干净装配。
9. **第九轮（§10.6）系统性关闭了“是不是没优化到位”的六个方向**：训练轮数曲线 200 轮见顶、链条组 100 轮最好（不是欠训练，略过训）；train OOF 低于 val 是 365 人的抽样而非训练问题（差距恒为 +0.04–0.05，流行率与死亡率相同）；四种神经网络设计（多任务 MLP 官方行 / person-period、分段线性编码、以 XGB 为偏置的残差网络）0.21–0.29，残差网络对树 Δ = −0.0016，差距来自样本效率而非输入格式；层次化集成收缩单调变差；费用 v3 在模型内不如 v2；深度 4 / 200 轮 / 800 轮 / 稠密强制筛选均 ≤ 现行。所有装配探测落在 0.3157 ± 0.001，提交不变。

## 1. 生成过程建模：这个任务到底在预测什么

### 1.1 Synthea = 一组独立的状态机模块

每个患者的记录是 m 个模块 $M_1,\dots,M_m$（心血管、前列腺癌、肺癌、骨质疏松、痴呆、妊娠、外伤、上呼吸道感染……）各自运行的事件流的并集。每个模块是一个（半）马尔可夫链，转移概率依赖年龄、性别、少数患者属性（吸烟、BMI、种族）和**同一模块内的前序状态**。目标 $Y_k = \mathbf 1\{\text{首次进入状态 } s_k \in (a, a+5y]\}$。

于是 $P(Y_k=1\mid H)$ 的可预测性由模块结构决定，不由"模型大小"决定：

- **无记忆模块**（外伤、急性上呼吸道感染）：常数或仅随年龄变化的风险 $h_k(\text{age},\text{sex})$，
  $P(Y_k=1\mid \text{未曾患}, H)=1-\exp\!\big(-\int_a^{a+5}h_k\,ds\big)$，与 $H$ 中除年龄/性别外的一切无关。贝叶斯最优打分是年龄的单调函数，**AP 的天花板就是年龄/性别模型的 AP**。
- **链条模块**：$s_k$ 的前序状态会以确定性或高概率出现在 anchor 之前（PSA/活检 → 前列腺肿瘤；骨质疏松 → 病理性骨折；CHD → 心梗；房颤 → 中风；避孕药 → 妊娠）。贝叶斯最优打分是少数稀疏指示变量的阈值函数，信息密度极高。
- **终末模块**：$s_k$ 是死亡前的最后状态（心梗、肺炎、CHF、肺癌、前列腺转移）。

### 1.2 窗口不是随机的：anchor = 记录末 5 年

记 $T_{end}=\min(\text{死亡}, 2021\text{-}07)$，$a=T_{end}-5y$，$D=\mathbf 1\{\text{窗口内死亡}\}$。train/val 中 $P(D)=0.43$，且 $D$ 与"记录是否结束于 2021 年"几乎一一对应（记录结束于全局末期 400 天内者死亡率 2.2%，其余 91.4%）。

| 目标 | 阳性中死者占比 | 至风险人群发病率 死者/生者 | 窗口内首诊中位时间（年） |
| --- | ---: | ---: | ---: |
| 心梗 | 98.7% | 0.127 / 0.0013 | **4.98**（p10 = 4.52） |
| 肺炎 | 100% | 0.111 / 0.000 | **4.97** |
| CHF | 97.8% | 0.192 / 0.003 | 3.05 |
| 中风 | 72.8% | 0.146 / 0.041 | 4.85 |
| 前列腺肿瘤 / 原位癌 / 转移 | 96% / 96% / 100% | 0.100 / 0.0026 | 2.1 / 2.3 / 3.0 |
| 疑似肺癌 / NSCLC / NSCLC I 期 | 97% | 0.070 / 0.0013 | 2.0（p10 1.0，p90 3.0） |
| 复发性直肠息肉 | 87% | 0.053 / 0.006 | 2.1 |

心梗和肺炎的"首诊"就是死亡当天；肺癌在窗口第 1–3 年确诊是因为 Synthea 肺癌模块的生存期固定在 2–4 年。所以这 10 类标签在数学上是
$$P(Y_k\mid H)=P(D{=}1\mid H)\,P(Y_k\mid H,D{=}1)+P(D{=}0\mid H)\,\underbrace{P(Y_k\mid H,D{=}0)}_{\approx 0},$$
即"会不会死 × 死于什么"。这也是为什么密集监督失败（§3.3）。

### 1.3 三类目标的分解（val，各模型）

| 目标组 | 常数 | 年龄+性别 LR | Transformer×3 | GBM | 融合 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无记忆意外（15 类） | 0.083 | 0.091 | 0.105 | 0.103 | 0.103 |
| 死亡对齐终末（10 类） | 0.036 | 0.097 | 0.489 | 0.496 | 0.538 |
| 模块链条（15 类） | 0.046 | 0.172 | 0.247 | 0.247 | 0.278 |
| 对 mAP 的贡献（组均值×组大小/40） | | 0.034 / 0.024 / 0.065 | | 0.039 / 0.124 / 0.093 | 0.039 / 0.134 / 0.104 |

意外组 15/40 的权重永远只能贡献约 0.04；现实的 val 天花板大约在 0.30–0.33（意外 0.10、终末 0.6、链条 0.35）。超过这个数的"提升"基本是噪声。

### 1.4 把问题写成一个统一的概率模型

记 $Z_a$ 为 anchor 时刻各模块的隐状态（例如前列腺模块处于"已活检、待诊断"，骨骼模块处于"骨质疏松已 3 年"），$X$ 为患者属性（年龄、性别、种族、吸烟、BMI），$E$ 为记录结束时间，$D=\mathbf 1\{E=\text{死亡}\}$。Synthea 的生成过程给出

$$P(Y_{1:40}\mid H)=\sum_{z}P(z\mid H)\Big[P(D{=}0\mid z)\prod_k P(Y_k\mid z, D{=}0)+P(D{=}1\mid z)\sum_{\pi}P(\pi\mid z,D{=}1)\,P(Y_{1:40}\mid z,\pi)\Big],$$

其中 $\pi$ 是死亡通路（肺癌、前列腺癌、心脏、痴呆→肺炎、中风、结直肠……），终末目标是 $\pi$ 的近似确定性函数（这就是肺癌三联 Jaccard 0.9–0.99、前列腺对 0.79 的来源）。这个式子直接给出建模分工：

| 分量 | 数学对象 | 经典方法 | 本场景实现 |
| --- | --- | --- | --- |
| $P(z\mid H)$ 隐状态重构 | 历史 → 各模块当前状态与停留时间的充分统计量 | 特征工程 / 序列模型的状态估计 | 每个编码的计数、最近/首次出现距今、数值末值与趋势；Transformer 侧用 wide 通路把这些量直接送进头 |
| $P(D\mid z)$ 门控 | 二分类 | 多任务辅助头 / stacking 特征 | 死亡头（训练标签合法），本数据 AUROC 0.98 |
| $P(\pi\mid z,D{=}1)$ 竞争风险 | 多分类，原因别风险 | Prentice 1978 / Fine–Gray / 多项 logit | 只在死亡训练患者上拟合的通路 softmax；终末目标 = Σ_π P(π)·P(Y_k|π) |
| $P(Y_k\mid z,D{=}0)$ 链条与无记忆 | 带延迟的半马尔可夫风险 / 常数风险 | 生存分析、经验贝叶斯收缩 | GBM（含"距前驱多久"特征）；无记忆目标按 OOF 收缩到年龄/性别模型 |
| 估计方差 | $n=2791$，每类阳性中位 80 | bagging、CV 集成 | 5 折 × 2 重复的折模型平均，GBM 与 Transformer 融合 |

**死亡通路的实际结构**（train+val 死者 1354 人，按窗口内终末目标定义）：心脏(CHF/心梗) 31%、中风 13%、痴呆→肺炎 11%、结直肠 9%、前列腺 9%、肺癌 7%、Alzheimer 组 6%；58% 的死者恰有一条通路，29% 没有任何目标通路（死于乳腺癌、枪伤、心脏骤停等非目标原因），13% 有两条以上（主要是高龄者的心脏+Alzheimer 并发）。通路之间近似互斥（肺癌与肺炎同现 0 例），这就是用一个 softmax 而不是 10 个独立 sigmoid 的依据；多通路者取离记录末最近的终末诊断为主通路。

**链条目标的风险对"距前驱多久"几乎不敏感**（train+val 至风险人群）：骨质疏松确诊后 0–1 / 1–2 / 3–5 / 8–12 / >12 年内，窗口内病理性骨折概率分别 0.21 / 0.45 / 0.26 / 0.26 / 0.33（无骨质疏松 0.007）；CHD 确诊后各区间心梗概率 0.2–0.4（无 CHD 0.022）；房颤后中风 0.17–0.39（无房颤 0.079）；前列腺活检后肿瘤 0.58–0.82，且至风险者的活检全部发生在 anchor 前 5 年内（更早活检者已确诊、不在风险集）。即 Synthea 这些模块是**按状态的常数风险**（马尔可夫），进入状态与否才是信息，停留时长和事件先后几乎不携带额外信息。这解释了为什么"编码是否出现过"的词袋特征足以读出链条、为什么序列顺序建模在这里收益很小，也说明 Transformer 的位置/时间编码不是瓶颈。

**测试集的截断方式**（影响哪些字段合法）：test 各表 START 全部 < anchor，且 **STOP > anchor 的值全部被置空**（用药表 1049 条空 STOP ≈ train 中"空 + 晚于 anchor"的比例）。因此 STOP 不含未来信息；若要用"anchor 时仍在用药"特征，训练侧必须同样把 STOP > anchor 置空以保持分布一致。该特征信号很弱（死者/生者仍在用药比例 4.1% vs 3.2%），非优先项。

**为什么逐时间步密集监督不可能有效**（严格版）：官方 anchor $a^*=E-5$ 是轨迹的确定性函数。把"随机时刻 $t$ 的 5 年窗口"当训练样本，相对于官方分布的重要性权重是 $w(t)=\mathbf 1\{t=a^*\}/(1/L)$，退化到只有官方位置非零；因此任何重加权都无法从密集样本恢复官方分布，密集标签只能作为先验/辅助任务。实测 dense_mix ≈ sparse 说明这个先验在本数据上价值≈0。

**生成式（ETHOS 式）路线为什么暂不推荐**：等价于用 next-event 模型模拟未来并按 $D$ 做拒绝采样，但全部训练 token 只有 ~50 万，模拟分布的方差远大于判别式两阶段模型。

## 2. 问题一：评估噪声与选模（实验设计）

**数学。** 固定模型下，单类 AP 估计的抽样方差由阳性数决定。模拟（高斯打分，流行率 3%）：

| 验证集 | 阳性数 | 真 AP=0.1 | 0.3 | 0.6 |
| --- | ---: | ---: | ---: | ---: |
| val 365 人 | 11 | SD 0.055 | **0.116** | 0.132 |
| train OOF 2791 人 | 84 | 0.022 | 0.047 | 0.052 |

40 类平均后 mAP 的 SD：val ≈ 0.013（实测 bootstrap 0.0133），OOF ≈ 0.006（实测 0.0058）。再加上早停在 ~10 个有噪声的 epoch 上取 max，$E[\max]$ 比真值高约 1 个 SD（赢家诅咒），所以 val 数字系统性偏乐观 0.01–0.02。又因为同一批 CV 模型在 val 子集上 0.244、在 train 子集上 0.209，**val 这 365 人本身就是一个偏容易的样本**；两次重复 CV 都是如此，差距在终末组最大（中风 +0.17、肺炎 +0.16、原位癌 +0.32）。

**经典方法。** K 折 / 重复 K 折交叉验证、嵌套 CV、配对 bootstrap、one-standard-error 规则、把"选择用"数据和"报告用"数据分开。

**本场景适配。**
1. 所有模型选择、早停 epoch、超参、融合权重都在 **train 的 5 折 × 2 次重复 OOF** 上做（2791 人，SD 0.006）；只接受 Δ > 0.012 的改动。
2. 官方 val 只在最后报告时用一次，且同时报告 OOF 数字，并说明 val 偏易。
3. 折模型直接做集成（5 折 × 3 种子 = 15 个模型，免费的方差缩减）。
4. 停止 A/A 复现、2×2 因子等在 365 人上分辨不出效应的实验。

## 3. 问题二：死亡对齐的窗口（informative censoring / 终末事件）

**数学。** §1.2 的混合分解。关键量 $P(D=1\mid H)$ 在本数据里几乎可识别：用 anchor 前历史的 GBM 预测 $D$，val AUROC **0.983**；去掉 QALY/DALY/QOLS 三个观测后仍 **0.958**；再加上 anchor 日历年 0.998。原因是日历年代可从历史回归出来（$R^2=0.85$，MAE 3 年）：

- QALY/DALY/QOLS 观测只存在于 2011-01-01 之后；生者 99.5% 有、死者 12.1% 有（死者 anchor 中位 1995 年，生者 2016 年）。
- 其他年代代理：流感疫苗编码(IMM:140)首次/最近出现时间、wellness 就诊间隔、吸烟状态观测(72166-2)、部分药物编码。

**这意味着什么。** (i) 这是数据集构造造成的 artifact，不是临床信号；(ii) 测试集按同样方式构造（test anchor 落在"生者带"的比例 53.9% vs train/val 56.8%）；(iii) 所有模型都在隐式利用它，Codex 的 Transformer 也是（QALY/DALY 作为 token 进入了词表）；(iv) 无法完全剔除——去掉 QoL 特征后 GBM 从 0.2565 降到 0.2467，但年代代理仍在。

**经典方法。** 竞争风险 / 原因别风险（cause-specific hazard，Prentice 1978）、分层/混合专家模型、多任务学习（Caruana 1997）、带辅助目标的层次分类。

**本场景适配。**
1. **不要把 anchor 日历日期当显式特征**。它对 GBM 没有增益（0.2548 vs 0.2565，历史已含年代信息），却会被评审视为投机。
2. **显式建模 $D$**：训练标签里加入"窗口内死亡"（来自训练患者的未来，与 40 类标签同属"标签"而非"输入"，合法）。对 Transformer 做多任务头；对 GBM 做两阶段：$\hat p(D\mid H)$ 作为 stacking 特征，或 $\hat p_k=\hat p(D\mid H)\,\hat p(Y_k\mid H,D{=}1)$ 的因式分解（终末组），后者让心梗/肺炎/CHF/肺癌/转移共享"会死"因子，等价于一个低秩共享头。
3. **在报告里明确写出**：窗口定义导致的死亡耦合、三组分解、以及"去掉 QoL 观测"的敏感性分析（0.2467）。这比隐瞒更能体现"leak-aware"。

### 3.3 为什么密集监督和多 landmark 增强反而失败

直觉上 2791 个标签太少，应当"每个时间步都打一个 5 年标签"（监督单元从 10 万个变成 2300 万个）。实测（同一 backbone、同预算、同早停，3 种子）：

| 监督方式 | val mAP | 心梗 AP | 肺炎 AP | Alzheimer AP |
| --- | ---: | ---: | ---: | ---: |
| 仅官方 anchor（稀疏） | 0.2098 ± 0.0089 | 0.59 | 0.58 | 0.30 |
| 每个事件位置都打标签（密集） | **0.1783 ± 0.0031** | 0.19 | 0.11 | 0.13 |
| 密集 + 官方各占一半 | 0.2106 ± 0.0086 | – | – | – |
| GBM，官方 anchor | 0.2567 | | | |
| GBM，+ anchor−1…−10 年的 landmark（行数 ×11） | 0.2524（加权 0.2499，加指示 0.2560） | | | |

数学上，密集位置估计的是**自然风险** $P(\text{first}_k\in(t,t+5]\mid H_t)$，$t$ 为任意时刻；官方目标是**以"anchor 恰好放在记录末 5 年"为条件**的分布，二者在终末组差一个 $P(D\mid\cdot)$ 的因子（随机时刻 5 年内死亡率 ≈5%，官方 anchor 处 43%）。密集模型学到"心梗 5 年内很少发生"，在官方位置就把终末组全部压低——恰好是 mAP 贡献最大的那组。结论：**官方窗口的稀疏监督必须是主损失**；密集/增强只能作为辅助或预训练（dense_mix 不伤不助）。

## 4. 问题三：链条信息在历史里，但 Transformer 没有读出来（表示 + 样本复杂度）

**证据。** 训练集至风险人群中的前驱提升（$P(Y\mid c)$ / 基率）：

| 目标（基率） | 前驱事件 | $P(Y\mid c)$ | 提升 |
| --- | --- | ---: | ---: |
| 前列腺肿瘤 (0.043) | 前列腺活检 / PSA / 直肠指检 | 0.69 / 0.64 | 16× |
| 前列腺原位癌 (0.034) | 同上 | 0.60 / 0.51 | 18× |
| 肺炎 (0.048) | 多奈哌齐 23mg / 他克林 / 美金刚（痴呆药） | 0.57 / 0.51 / 0.46 | 12× |
| 病理性骨折 (0.035) | 骨质疏松 / 阿仑膦酸 | 0.29 / 0.27 | 8× |
| 心梗 (0.055) | CHD / 硝酸甘油 | 0.33 | 6× |
| 中风 (0.086) | 房颤 / 电复律 / 华法林 | 0.23 | 2.7× |
| Alzheimer (0.030) | 头颅 MRI / CT / 认知障碍 | 0.31 / 0.29 / 0.18 | 10× |
| 正常妊娠 (0.027) | 各类避孕药 | 0.52–0.74 | 19–27× |
| 肥胖 (0.043) | 儿童 BMI 百分位末值（连续） | AUROC 0.88 | |

树模型一次分裂就能读到这些；val 上 GBM vs Transformer：前列腺 0.91 vs 0.69、原位癌 0.93 vs 0.44、心梗 0.68 vs 0.49、肥胖 0.58 vs 0.31、Alzheimer 0.38 vs 0.18。

**数学。** 对链条目标，贝叶斯最优打分 $\approx \sigma(\beta_0+\sum_j\beta_j x_j)$，$x_j$ 是"历史中是否出现编码 $c_j$ / 最近一次距今 / 某化验末值是否超阈值"这类稀疏特征。线性或树模型在 $d$ 个稀疏特征中找 $k$ 个相关特征的样本复杂度是 $O(k\log d)$ 量级的阳性数；而因果 Transformer 必须 (a) 让 attention 在 ≤511 个位置里检索到一个稀有 token（随机初始化时该 token 的梯度份额约 1/511），(b) 经过 3 层把它搬到最后一个位置的读出向量，(c) 只有 ~100 个阳性、每 batch 平均 0.6 个阳性来学这件事。同时 8 档分位数分箱把连续值截断（BMI 的分箱边界 [27.2, …, 29.7, 30.3] 跨在 30 上）。

**经典方法。** 特征工程 + 梯度提升树（Chen & Guestrin 2016；小样本表格 EHR 的默认强基线）、Wide & Deep（Cheng et al. 2016：把稀疏计数直接线性接到输出）、stacking（Wolpert 1992）。

**本场景适配。**
1. **计数特征 GBM 作为主模型**（已做）：每个编码的全史计数、近 5 年/近 1 年计数、最近/首次出现距今、数值观测的末值/极值/近 5 年均值、年龄/性别/历史长度、既往目标状态。350 个 token + 59 个数值码 = 1688 维，单模型 0.2565，训练 20 秒。
2. **Transformer 加 wide 通路**：logits = head(h_PRED) + W·log1p(bag-of-token counts)。实测 3 种子 0.2357 ± 0.0130 vs 同脚本稀疏基线 0.2310 ± 0.0104（macro-AUROC 0.764 vs 0.746）：方向正确但在噪声以内，需要在 OOF 上确认。注意 wide 通路只看到被截断的最近 511 个事件；GBM 用的是全史计数，这是二者仍有差距（0.2357 vs 0.2565）的一个原因。
3. 数值观测用"分箱 token + 连续标量×可学习向量"双重编码，补回阈值信息。
4. **GBM 与 Transformer 融合**：在 val 上两者看似互补（Transformer 在肺癌三联、转移、步态/微出血更好），50/50 平均 0.2773；但 §7.3 的 5 折 OOF 显示 Transformer 在这些目标上同样不如 GBM（肺癌三联 0.19–0.21 vs 0.23–0.27，转移 0.31 vs 0.48，步态 0.035 vs 0.067），"互补"是 val 上 9–11 个阳性造成的噪声，OOF 最优权重 0.9 在表格侧。

## 5. 问题四：过拟合 / 记忆（容量 vs 样本）

**证据。** 2791 人、1.06M 参数；训练 mAP 第 15 轮 0.81、第 19 轮 0.90，val 在第 6–11 轮见顶 0.22；val BCE 从第 7 轮起上升。每个患者的 500 个 token 序列是唯一的，模型在记患者。

**数学。** 密集监督实验给出一个有用的反证：密集模型在官方位置的训练 mAP 最高只到 0.37（几乎没记忆），val 却更差。说明**限制 val 的不是记忆本身，而是信号提取（§4）和天花板（§1.3）**。因此"加大正则化"预期收益有限；真正有效的是降低方差（集成）和改变输入表示。

**经典方法。** 早停（已有）、集成/bagging（Breiman 1996；深度集成）、多任务辅助标签、自监督预训练、输入增强。

**本场景适配。**
1. **种子/折集成**：3 种子概率平均 0.2543 vs 单模型 0.221（+0.03，比 Codex 所有结构实验加起来都大）。
2. **多任务辅助标签**（同一官方窗口内所有 ≥10 阳性的新发诊断 49 类 + 死亡）：实测 0.2206 ± 0.0025 vs 同脚本稀疏 0.2310 ± 0.0104，**无增益**；与 wide 通路叠加 0.2429 ± 0.0109，仍在噪声内。辅助标签与主标签共享同一 artifact，没有带来新信息。
3. 4 轮 next-event 预训练在 Codex 的消融里 (去掉预训练 0.2230 vs 0.2281) 也分不出效应；全部训练 token 只有 ~50 万，不建议在预训练上继续投入。
4. 可试但未验证：事件 dropout / 随机子序列截断、d_model 64、更强 weight decay。预期都在 ±0.01 内。

## 6. 其他被当成主因但不是瓶颈的问题

**batch 内稀有正例（Codex 的 ranking-loss 方向）。** 目标 $k$ 的头的梯度对 batch 组成是无偏的，变化的只是方差和共享 backbone 的分配。Codex 冻结 encoder 后比较 BCE/RankNet/ListNet/SmoothAP/RLOO/GRPO，最好者比 BCE 高 0.00012（CI [−0.0023, +0.0032]），已经证明这不是瓶颈。若仍想处理，梯度累积到有效 batch 64–128 或逐类损失归一化即可。

**BCE/Brier 改善而 mAP 下降。** macro AP 对每类的单调变换不变，Brier/BCE 改善来自不同 epoch 的选择与噪声，不需要在建模上做任何事。提交要求概率，用 OOF 做逐类温度缩放即可，不影响排序。

**重复目标。** 肺癌三联 Jaccard 0.89–0.99，步态异常/脑微出血 1.00（同一天、同一批 11 人），前列腺肿瘤/原位癌 0.79。它们在 40 类里被重复计分。对同组目标做预测平均是无偏的方差缩减；GBM 上实测 OOF 0.2093 vs 0.2094，无损无益，可留作安全处理。

**历史截断。** Codex 的 256/512/1024 消融（0.2278/0.2281/0.2252）本身已说明不是瓶颈；GBM 用全史计数（不截断）得到的收益来自表示而非长度。

### 7.2 迭代 3：竞争风险结构化输出（`analysis/pipeline_v3.py`）

| 模型 | OOF mAP | 终末 10 类 OOF | 通路 15 类 OOF | val mAP |
| --- | ---: | ---: | ---: | ---: |
| (a) 直接 GBM | 0.2104 | 0.416 | 0.327 | 0.2557 |
| (b) 门控 × 独立 sigmoid | 0.2060 | 0.413 | 0.315 | 0.2471 |
| (c) 门控 × 通路 softmax × T | 0.1930 | 0.364 | 0.281 | 0.2400 |
| (a)+(b)+(c) 平均 | 0.2115 | 0.421 | 0.330 | 0.2516 |

通路 softmax 在死者上的 OOF 准确率 0.485（多数类基线 0.29）：**死因只能中等程度地预测**，而且把它压成 8 个互斥类丢掉了直接模型能用的细粒度信息（例如 CHF 与心梗虽同属"心脏"通路，前驱不同）。结论与 7.1 一致：当 $D$ 几乎是 $H$ 的确定函数时，结构化分解不提供额外信息，只能作为集成成员贡献 +0.001。这是一个干净的负结果——**问题不在输出结构，而在输入信息量**：至风险人群里的死因信号就只有这么多。

Transformer（multi_wide 变体，2 种子 × 5 折，每折用官方 val 早停、对留出折预测）：

| | OOF mAP（2791 人） | val mAP |
| --- | ---: | ---: |
| Transformer 折模型（10 个平均） | **0.1751** | 0.2490 |
| 表格模型 v3 | 0.2141 | 0.2521 |

**这推翻了 §7 里"融合 +0.03"的结论。** 在 2791 个训练患者的留出预测上，Transformer 比 GBM 低 0.04，最优融合权重 0.9 落在表格侧，融合增益只有 +0.0006。此前 val 上 0.277–0.289 的融合分数来自三重乐观：val 偏易（§2）、Transformer 用 val 早停（val 数字被选择过）、融合权重也在 val 上挑。单模型 val 与 OOF 的差距：GBM 0.252 vs 0.214（差 0.04，主要是 val 偏易），Transformer 0.249 vs 0.175（差 0.07，叠加了早停选择）。

追加实验（`analysis/cv_transformer_hybrid.py`）：把干净数据集的**全史** token 计数 + 数值末值/极值（714 维）作为 wide 通路接到同一 Transformer 的输出上，2 种子 × 5 折 OOF = **0.1733**（折内留出均值≈0.19，各折模型分数尺度不一致使拼接 OOF 再低一些），val 折集成 0.2518。即使给 Transformer 与 GBM 同源的全史信息，线性 wide 通路也复现不了树模型的阈值规则（BMI≥30、PSA 阈值），而 2,233 人的训练量不足以让 backbone 学到它们。结论：在这份数据上序列模型不是正确的归纳偏置，只能作为 0.1 权重的集成成员保留。

对测试集的诚实预期因此是 **0.21–0.22**（若测试患者像训练患者）到 0.26（若像 val），而不是 0.28。Codex 提交版 6 成员集成的 val 0.2677 同样含这两层乐观，其 OOF 未知但不会例外。

`predictions_final.csv` = 0.9 × 表格 v3 + 0.1 × Transformer 折集成，重复目标组平均，已通过 `validate-submission`；根目录原 `predictions.csv` 未动。

### 7.4 信息天花板检验（`analysis/information_ceiling.py`）

每个目标在 train 5 折 OOF 上比较三个模型：年龄/性别 LR；年龄/性别 + 折内按精度选出的 10 个前驱 token 指示变量的 LR；直接 GBM（2221 维特征）。

| 模型 | OOF mAP |
| --- | ---: |
| 年龄/性别 LR | 0.1038 |
| + 10 个前驱指示变量 | 0.1635 |
| GBM 全特征 | 0.2104 |

GBM 相对 10 变量 LR 的增量几乎全部集中在 5 个目标：肥胖 +0.43（连续 BMI 值）、心梗 +0.26 与 CHF +0.26（死亡/年代代理：QoL、就诊频率、数值）、转移 +0.23、前列腺肿瘤/原位癌 +0.16。其余 35 个目标的差在 ±0.05 以内，其中 15 个意外目标差 <0.01。也就是说：**对绝大多数目标，10 个二值前驱 + 年龄性别已经达到数据的信息上限；GBM 多出来的分来自连续数值与年代代理，不来自"更复杂的模式"。** 这与 §1.4 的马尔可夫按状态常数风险结论一致，也解释了为什么 Transformer、密集监督、结构化输出、ranking loss 都不可能在这份数据上带来大幅提升。

两点提醒：(i) 同一架构、同一数据、只因 RNG 消耗顺序不同（`dense_transformer.py` 与 `aux_transformer.py` 的稀疏基线），3 种子概率平均分别是 0.2156 和 0.2518，差 0.036——这就是 val 上"结构改进"的噪声量级；(ii) 融合权重和配置是在 val 上看过结果后选的，0.2889 含选择偏差，可靠的说法是"GBM 与 Transformer 融合稳定落在 0.27–0.29"，最终权重应在 OOF 上定。

## 8. 推荐的训练范式（按优先级，已按 OOF 结果修订）

1. **评估框架先行**：`train` 5 折 × 2 重复 OOF 作为唯一的决策指标；val 只报告一次；逐组（意外/终末/链条）报告。任何在 val 上做早停/选模/选权重的数字都要标注为"已选择"。
2. **主模型：计数特征 GBM**（OOF 0.214），逐目标训练，折模型集成；特征按 §4.1，不用 anchor 日历日期；可选：三种结构化变体 (a)(b)(c) 平均（OOF +0.001）。
3. **Transformer 的角色**：题目推荐序列模型，报告里应保留并如实给出它的 OOF（0.175）与 val（0.249）；融合权重按 OOF 取 0.1 左右，而不是 0.5。要让 Transformer 真正有用，需要改的是输入信息量（全史词袋通路而不是截断 511 事件的计数、数值连续编码），而不是损失函数或注意力方向。
4. **融合与后处理**：OOF 定权重；重复目标组平均（无害）；OOF 温度缩放输出概率。
5. **报告**：披露窗口-死亡耦合与年代代理、三组分解和天花板、去 QoL 敏感性分析（0.2467 / OOF 0.2009）、val 偏易及 OOF 数字；把"为什么密集监督失败""为什么 val 上的融合增益是假的"写进 interpretation——这比涨分更能体现对问题的理解。

预期：**OOF ≈ 0.215，val ≈ 0.256**；测试集像训练患者则 ≈ 0.21–0.22，像 val 则 ≈ 0.26。再往上要么是噪声，要么是在利用 artifact 本身（不建议）。

## 10. 基于数据结构的模型设计（样本少 → 模型小，但信息要用足）

把 §1 的生成过程和 `docs/data_audit.md` 的清洗结果合起来，一个"与数据匹配"的模型应满足四条，每条对应一个可检验的实验：

| 数据特点 | 归纳偏置 | 经典模型 | 实验 |
| --- | --- | --- | --- |
| 模块独立、按状态常数风险 → 对数风险近似**加性**，交互弱（GBM num_leaves 8 与 4 同分） | 稀疏加性模型 | L1 逻辑回归 / GAM / boosted stumps（EBM 的雏形） | `sparse_additive.py` |
| 每目标仅 10–30 个相关特征，总维 2,300，阳性 30–740 | 稀疏 + 跨目标收缩 | 折内单变量筛选（SIS）、向年龄性别基线收缩、经验贝叶斯 | `tune_v4.py` (b)(e) |
| 常数风险 ⇒ 训练患者 anchor 前每个人年都是合法样本（≈12 万人年 vs 2,791 个窗口）；但终末 10 类窗口与死亡对齐，不能这样用 | 离散时间生存模型（person-period），只用于 30 个非终末目标 | Cox / 离散时间 logistic 风险模型（Allison 1982）、landmarking | `person_period.py` |
| 终末组 = 死亡门控 × 死因，门控已由历史确定（0.997） | 直接判别模型即可 | — | 已验证（§7.2） |

此外模型族多样性（ExtraTrees）与 5 种子 bagging 作为方差控制。所有比较在 train 5 折 × 2 OOF 上进行；逐目标选择用 rep0 选、rep1 评，避免选择乐观。

### 10.1 结果（持续更新）

**Person-period 风险模型（30 个非终末目标，XGBoost-GPU，按患者 5 折）**：每 2 年一个 landmark，训练行从 2,791 增至 52,352。

| 模型 | 30 类 OOF 均值 AP | 对 40 类 mAP 的影响 |
| --- | ---: | ---: |
| 仅官方 anchor（同特征、同模型） | 0.1377 | — |
| person-period，均匀权重 | **0.1545** | ≈ +0.013 |
| person-period，官方行 ×5 | 0.1550 | ≈ +0.013 |

收益恰好落在理论预测的位置：Alzheimer 0.159→0.340、贫血 0.132→0.240、肥胖 0.501→0.593、胎儿并发症 0.098→0.182、骨质疏松 0.165→0.212、妊娠 0.487→0.529、CHD 0.117→0.143；无记忆的急性感染略降（支气管炎 −0.046、病毒性鼻窦炎 −0.026，官方窗口里年龄分布与全生命周期不同），房颤/中风/病理性骨折持平。**这是本项目第一个由"数据结构推理"直接带来的、在 OOF 上可见的建模收益**，而且是在样本不增加的情况下通过正确使用已有人年实现的。逐目标是否采用由装配阶段在交叉拟合的 OOF 上决定。

**最终装配**（`analysis/assemble_final.py`：逐目标 Caruana 贪心集成选择，患者级交叉拟合评估）：16 个候选族 → **交叉拟合 OOF 0.2225 / val 0.2726 / val macro-AUROC 0.7747**（LightGBM 版 person-period 单独 0.2183，与 XGBoost 版一致，证实收益与模型实现无关）。对比：干净 GBM 单模型 OOF 0.2092 / val 0.2551；person-period 单独替换非终末目标 OOF 0.2195–0.2199。权重最大的成员是 person-period 各变体（合计 ≈0.38）、LightGBM 两配置（0.23）、XGB 平均（0.09）、Transformer（0.09）、加性模型（0.21，主要在意外组起平滑作用）。这是到目前为止诚实口径下的最好结果，比起点（0.2092）高 0.012，比 Codex 提交版的 val 0.2677 也高，而且有 OOF 背书。

**稀疏加性模型**：boosted stumps（深度 1，1,500 轮）OOF 0.1957 vs 深度 3 树 0.2092；批量 L1 逻辑回归最好 0.189（且未真正稀疏）。结论：纯加性不够，**低阶交互（年龄 × 状态、性别 × 状态）是必要的**，深度 2–3 的树是合适的容量；线性模型不进入最终装配。

用 min_child_weight=1 复核（排除"行数变多使叶子约束变松"的混淆）：仅官方 anchor 0.1419 → person-period 均匀 **0.1544**（+0.0125，折合 40 类 mAP ≈ +0.009），收益位置不变（Alzheimer +0.14、贫血 +0.10、胎儿并发症 +0.07、骨质疏松 +0.05、肥胖 +0.05），急性感染仍略降（支气管炎 −0.05）。结论成立：**对非死亡耦合的目标，用全部人年估计风险优于只用官方窗口**，最终装配按目标在交叉拟合 OOF 上取舍。

每年一个 landmark（102,695 行）不再增益：均匀 0.1536、按距 anchor 距离衰减加权 0.1526，与每 2 年的 0.1545 持平；人年数量不是瓶颈，landmark 密度到此为止。

**超参（XGBoost-GPU，rep0 选 / rep1 评）**：min_child_weight=20 对稀有目标灾难性（深度 2 下 0.153 vs 0.2015），因为 XGBoost 的叶子约束按 Hessian 之和计，流行率 3% 时 20 相当于每叶 ≥700 人；即使 min_child_weight=5（≈170 人/叶）的 XGBoost 基线（0.200）也低于 LightGBM 按样本数约束 min_child_samples=15 的 0.209。**LightGBM 叶子约束扫描**（num_leaves {4, 8} × min_child_samples {5, 15, 40}，rep1 诚实评估）：六个配置落在 0.2022–0.2050，差异在噪声内；六配置平均 0.2053 最稳，rep0 逐目标挑选反而 0.2035（选择噪声大于配置差异）。结论：在按样本数约束的范围内 LightGBM 对超参不敏感，不值得再调；装配中用配置平均作为该族成员。XGBoost 的 5 种子 bagging 因 GPU 共享下耗时过长且该族整体偏弱，中止。

### 10.2 第五轮迭代（2026-10-29）：从逐目标分解出发，再找信息

逐目标分解最终集成（train OOF，按组）：意外 15 类 0.096（流行率 0.087，lift 1.0–1.7，已是无记忆上限）；链条 15 类 0.217（lift 2–21，差异极大）；终末 10 类 0.415（lift 5–26）。因此可提升的只有链条与终末两组。这一轮按"先诊断、后建模"做了四件事：

**(1) 二层 stacking（`stack_l2.py`，Wolpert 1992）——负结果，但有逐目标价值。** 以各族 OOF 的 logit + 交叉拟合的 P(死亡|历史)（OOF AUROC 0.998）+ 年龄性别（+ 可选另一族对其余 39 个目标的 OOF）为输入，逐目标 LR 或 4 叶 GBM，三次 5 折交叉拟合：own+death LR 0.2186、GBM 0.2044、+others LR 0.2144、GBM 0.1998，全部低于贪心集成 0.2225（逐目标最优单族的 oracle 为 0.2312）。2,791 行上的二层模型对稀有目标过拟合，受约束的凸组合（贪心）更稳。但在少数目标上二层模型明显更好：肺炎 0.485 vs 最优单族 0.459、骨质疏松性骨折 0.356 vs 0.304、前臂骨折 0.116 vs 0.091——这些正是"自然风险 × 死亡/年代修正"有非线性交互的目标。四个 stacking 输出作为候选进入装配，由交叉拟合的贪心逐目标取舍。

**(2) Offset boosting（`pp_offset_gbm.py`）——负结果。** 经典风险回归的 offset 技巧：log-odds = logit(person-period 风险) + f(x)，f 为官方行上的小 GBM，只需学"自然窗口 → 记录末窗口"的修正。30 个非终末目标 OOF 0.1458，低于 person-period 单独 0.1536（lgb_clean 0.1408）：修正项在 2,791 行 × 2,317 列上学到的主要是噪声，把 pp 的信号也带偏了。结论：pp 与官方模型的结合应在输出层做凸组合（装配已在做），而不是在 logit 层做自由修正。

**(3) 机制探针（`mechanism_probe.py`）——两个有用的发现。**
- *肥胖的机制不是"成人 BMI 临近 30"*：末次 BMI 单变量 AP 只有 0.075（流行率 0.043），线性外推 2.5 年 0.117，而 GBM 0.505。Synthea 成人体重近乎常数，窗口内首次"BMI 30+"几乎都发生在青少年长大成人的过程中（年龄 13–20 + 儿童 BMI 百分位 59576-9）。所以对肥胖重要的是年龄 × 百分位 × 成长趋势，这正是树在做的事，person-period 的 0.573 已接近该机制允许的上限。
- *官方行上存在特征稀释*：手工子集（百级特征）的深度 3 GBM 在妊娠 0.582 vs 全特征 0.506、Alzheimer 0.270 vs 0.187、骨质疏松 0.196 vs 0.144、贫血 0.149 vs 0.134 上系统性更好；中风/CHD 持平。30–150 个阳性对 2,300 列时无关列的代价是真实的，person-period 之所以有效，一部分原因就是阳性数变多后稀释减轻。由此引出 (4)。

**(4) 嵌套特征块 + person-period 容量扫描（`block_gbm.py`，`pp_build.py` + `pp_sweep2.py`）。** 把列按数据块嵌套：S1 = 静态 + 40 个 prior 指示（~60 列），S2 = S1 + 数值摘要（~540 列），S3 = S2 + COND/MED token，all = 全部；官方行 LightGBM 与 person-period XGBoost-GPU（共享每折一个 QuantileDMatrix，at-risk 用零权重实现，比逐目标重建快 3–5 倍）各跑一遍，并给 person-period 加 is_official / yrs_to_end 指示后覆盖全部 40 个目标（终末组也进入扫描）。结果见下表（随运行更新）。

### 10.3 第六轮（2026-10-29）：0.23 到底卡在哪——上限、学习曲线与样本效率

前五轮回答的是"什么有用、什么没用"，没有正面回答"为什么只有 0.23"。本轮把这个问题拆成三个可区分的假设并逐一测量（脚本 `analysis/oracle_ceiling.py`、`ap_consistency.py`、`death_mixture.py`、`pp_mix.py`、`screen_gbm.py`、`pp_sweep2.py --frac`，日志在 `analysis/logs/`）：

- (a) **生成器的不可约随机**：标签是常数风险的掷币，任何信息都没用；
- (b) **信息只在窗口内产生**：决定事件的前驱转移发生在 anchor 之后，无泄漏模型拿不到；
- (c) **有限样本的估计误差**：信息在 anchor 前历史里，但每个目标 30–230 个阳性不够把它估出来。

三者的处方完全不同：(a) 放弃，(b) 放弃，(c) 才值得继续做模型。

**1. 分数的算术。** 常数预测的 AP = 风险集内流行率，40 类平均 **0.0575**（意外 0.087 / 终末 0.039 / 链条 0.040）。当前装配 0.2345 = (15 × 0.105 + 10 × 0.439 + 15 × 0.228) / 40，是随机的 4.1 倍。意外组即使其余 25 类全部完美，mAP 也只有 (15 × 0.087 + 25 × 1) / 40 = 0.66；这是任务本身的上限，不是模型的。

**2. 学习曲线：链条与终末组是样本受限，不是信息上限。** 在同一 5 折划分里把每折的训练患者随机抽到 25 / 50 / 75 / 100%，评估始终在完整的留出折上：

**3. Oracle 实验：死亡不是瓶颈；"窗口内信息"的上限测不出来。** 在官方行 LightGBM（OOF 0.2068）上加入不合法的窗口内信息，看 AP 往哪边动：

**4. 自洽性检验（`ap_consistency.py`）。** 把装配的 OOF 分数做交叉验证的 Platt 校准得到 p̂，按 y ~ Bernoulli(p̂) 抽签 300 次算"若模型风险就是真风险"的期望 AP：期望 0.272 vs 实际 0.228（isotonic 校准：0.261 vs 0.210），40 类里 17 类实际值低于期望的 5% 分位，0 类高于 95% 分位。即分数在高分尾部**过度自信**——高分段里混着被有限样本噪声抬上去的患者，这正是方差受限（假设 (c)）的表现，而不是校准问题（AP 只看排序）。作为尺度感：流行率 5% 时，要把 AP 做到 0.30，需要找出 5% 的人群其真实风险是平均的 10 倍（绝对 50%）；AP 0.17 对应 10% 人群 5 倍风险。AP 对稀有事件就是这么陡。

**结论（替代 §10.2 结论 (iii) 中"终末组的死因随机性是生成器自带"的说法）。**

1. 意外 15 类（占 mAP 的 15/40）：硬天花板，AP ≈ 流行率，学习曲线平坦，oracle 也只能靠同次就诊事件。任何建模都不会动它们。
2. 链条 15 类与终末 10 类：**不是信息上限，是样本受限**。信息在 anchor 前历史里（学习曲线仍以每 e 倍 +0.03 / +0.07 的速度上涨），但每类只有 30–230 个阳性、终末组只有 1,199 个死亡患者。训练集不能扩（val 只允许做选择，test 无标签），合法的只有样本效率手段：person-period（等价 ~1.5× 数据）、交叉拟合贪心装配（再 ~1.5×）是本项目里唯一两个成立的；死亡门控混合、二层 stacking 作为最终模型、offset boosting、更深的树、transductive 行都不成立。
3. 因此对这份数据与规则下的合理预期是 train 同分布 OOF ≈ 0.23–0.24，val 同分布 ≈ 0.28；再往上要么靠更多带标签的患者，要么接受噪声内的微小增益。

**10.5.2 费用字段的机理（`build_cost_features.py` / `build_cost_features_v2.py`）。** 会计恒等式不成立：把 train/val 全记录的 encounters TOTAL_CLAIM_COST + medications TOTALCOST + procedures / immunizations BASE_COST 加总，只占 EXPENSES+COVERAGE 的 0.5%–17%（中位比值 0.166）；COVERAGE 与表内 PAYER_COVERAGE 之和相关 0.98 但比值 0.43。即这两列是 Synthea 另算的终生累计（含保费等），不是表的求和，“终生减 anchor 前”得不到干净的窗口支出。于是做两阶段：用 anchor 前全部特征 + 交叉拟合 logit P(死亡) 训练 LightGBM 回归预测 log 终生费用（train 5 折交叉拟合 R² = 0.75 / 0.44 / 0.46 for COVERAGE / EXPENSES / 总额），残差 = 历史解释不了的那部分 = 窗口内治疗；再加 anchor 前 1 年 / 5 年支出窗口和残差 × P(死亡) 交互。效果（单变量 AUROC，train 至风险）：

### 10.6 第九轮（2026-10-30）：训练量、容量、神经网络与结合方式、集成层结构——系统性地回答“为什么不是 NN / 是不是没训够”

**10.6.1 是不是欠训练？不是，略微过训。** `rounds_curve.py`：官方行 LightGBM（学习率 0.03、8 叶、v3 特征），每个 (目标, 折) 训 1,200 轮，在不同轮数处评估 OOF：

| 轮数 | 整体 | 意外 | 链条 | 终末 |
| ---: | ---: | ---: | ---: | ---: |
| 50 | 0.2775 | 0.096 | 0.249 | 0.594 |
| 100 | 0.2859 | 0.095 | **0.261** | 0.609 |
| 200 | **0.2876** | 0.096 | 0.258 | 0.620 |
| 350（现用） | 0.2865 | 0.096 | 0.255 | **0.621** |
| 500 / 800 / 1200 | 0.2851 / 0.2835 / 0.2831 | | | |

整体 200 轮见顶后单调下降；链条组 100 轮最好，终末组 350 轮；40 个目标里 22 个的最佳轮数是 50 或 100。结论：轮数不是瓶颈，方向是按组少训。补充对照：筛选后的官方行模型（k=60）100 轮反而比 350 轮差（0.2719 vs 0.2768）——特征少时需要更多轮；person-period XGB 的 200 / 800 轮配置见补记。容量方向：person-period XGB 深度 4 在 v2 上 0.2907 / val 0.3582，对深度 3 的 0.2890 / 0.3590 为千分位差异。

**10.6.2 “train 比 val 低”不是欠训练。** train 的数字是 5 折 out-of-fold（每个患者由没见过他的模型预测），不是训练拟合；它和 val 一样是泛化数。差距从第一个模型到现在恒为 +0.04 到 +0.05（0.209 / 0.255 → 0.238 / 0.283 → 0.316 / 0.368），与模型容量和训练量无关；val 与 train 在各组流行率（意外 0.083 / 0.087、链条 0.046 / 0.040、终末 0.036 / 0.039）和窗口内死亡率（0.425 / 0.430）上几乎相同，差距来自 365 人、每目标中位 11 个阳性的抽样（mAP bootstrap SD ≈ 0.013）。对抗验证表明 test 更像 train，所以一切决策看 OOF。

**10.6.3 为什么 MLP / Transformer 不行，是输入吗，能不能和 XGB 结合？** 用同一套融合特征（历史 token + 数值 + 基因组 + 费用 v3）、5 折 × 3 种子、训练折内部 15% 早停（不碰 val）做了四个设计（`mlp_multitask.py`、`nn_variants.py`）：

| 设计 | OOF | val | 终末 / 链条 |
| --- | ---: | ---: | --- |
| 多任务 MLP（共享主干 + 40 头），官方行 | 0.2202 | 0.2940 | 0.467 / 0.185 |
| 多任务 MLP，person-period 行（行数 ×20） | 0.2116 | 0.2753 | 0.433 / 0.186 |
| 分位数分段线性编码（PLE）+ 可学习逐特征分段变换 + MLP | 0.2163 | 0.2927 | 0.428 / 0.202 |
| **残差网络**：以最强 XGB（`ppds_gcr:screen200`）的 logit 为固定偏置，小网络只学残差，输出零初始化、强正则 | 0.2945 | 0.3619 | 偏置模型单独 0.2960 / 0.3567 → Δ OOF −0.0016，val +0.005 |
| 对照：同特征的树模型 | 0.28–0.30 | 0.34–0.36 | 0.62 / 0.28 |
| 对照：序列 Transformer（Codex，预训练 + 微调，3 种子） | 0.17 | 0.25 | 装配权重 0.007 |

机理：(1) 每折 2,200 名患者、每目标中位 86 个阳性，MLP 首层就有 130 万参数，而深度 3 的树有效自由度是几百个阈值；(2) 最强信号都是阈值型（有无 DNA、变异数 > 10、费用残差超过某值、年龄段），树一次切分即得，MLP 要从连续输入学阶跃——但 PLE 把阈值做成了显式输入后也没有改善，说明**输入格式不是剩余差距的来源，样本效率才是**；(3) 多任务共享为负，因为 40 个目标的信号互不相关（中风靠基因组、肺癌靠费用残差、怀孕靠年龄性别、意外类无信号），这与 10.6.4 的集成层结论一致；(4) Transformer 还把容量花在顺序上，而 Synthea 的模块是独立状态机，窗口内发病由 anchor 时刻的状态（哪些事件发生过、多久以前、最近的值）决定，Codex 的截断长度和预训练消融都证明顺序不携带信息。结合方式：输出层结合（装配）已经在做，但 0.22 对 0.30 的成员拿不到权重；**残差层结合是最合理的形态**（NN 作为 boosting 的下一级弱学习器只学树漏掉的光滑交互），实测在 OOF 上为零——树没有留下可学的系统性残差。特征层结合（叶子索引进 NN / NN 隐层进树）在这个样本量下前者复现树、后者取决于 NN 隐层的质量，不再投入。**结论：在 2,791 名患者、阈值型稀疏信号的条件下，树的样本效率优势不是 NN 的输入或训练细节能弥补的；NN 的四个版本留作装配候选，由交叉拟合决定权重。**

**10.6.4 集成层结构：层次化收缩为负。** `assemble_final.py --shrink α [--shrink-level group|module]`：逐目标贪心权重向所属组（意外 / 链条 / 终末）或 Synthea 模块的平均权重收缩，同样的对半交叉拟合评估。α = 0 / 0.3 / 0.6 / 1.0 → 0.3157 / 0.3113 / 0.3013 / 0.2846；模块级 α = 0.5 → 0.3133（val 0.3690）。收缩越强越差，说明逐目标权重承载的是真实的目标特异结构而非选择噪声。

**10.6.5 费用 v3（+ 保险方构成）。** `build_cost_features_v3.py`：anchor 前就诊 / 用药按 10 个 PAYER 的份额、最近一次 PAYER、PAYER 数，加入费用回归后 R² 从 0.75 / 0.44 / 0.46 升到 0.78 / 0.87 / 0.87（COVERAGE / EXPENSES / 总额），残差对肺癌三联 0.845 → 0.860、总额残差 0.64 → 0.77、转移 0.657 → 0.674。但进入模型后不如 v2：官方行筛选 k=200 0.2818 vs 0.2840，无历史模型 0.2558 vs 0.2595，特征块 S3 0.2811 vs 0.2799（±）。30 个 PAYER 列的稀释抵消了残差的改进，v2 仍是主线，v3 模型仅作多样性候选。

**10.6.6 补记：person-period 上的训练量 / 容量 / 筛选变体与本轮装配结论。** v2 数据集上：XGB 深度 3 的 200 轮 0.2841（400 轮 0.2890）、深度 2 的 800 轮 0.2783、深度 4 的 600 轮 0.2907；把 80 个稠密模态列（基因组计数、全部费用列）强制保留在筛选集里的 K=200 变体 0.2894 / val 0.3577（普通筛选 0.2960 / 0.3567）——强制保留反而稀释。官方行筛选模型 100 轮 k=200 0.2814（350 轮 0.2840）。装配探测（在 41 个候选上加入新候选，秩平均、5 次对半交叉拟合）：+5 个最强新候选 0.3154 / 0.3624，+14 个全部新候选 0.3148 / 0.3621，+训练量 / 稠密筛选 / 深度 4 / 残差网络 5 个 0.3156 / 0.3680。全部在现行提交 **0.3157 / 0.3676** 的 ±0.001 内，候选越多越不利。**第九轮不更换提交。** 结论：在当前数据与模态集合下，训练量、容量、筛选规模、神经网络（四种）、集成层结构、费用 v3 六条轴都已到平台；提交的交叉拟合 OOF 0.3157 是这套数据诚实口径下的当前上限估计，剩余的只有噪声带内的抖动。
