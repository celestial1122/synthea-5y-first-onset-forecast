# 优化研究记录（2026-10-28）

本轮先诊断截断，再完成 **10 组 × 3 个种子（17、42、73）**。原版 seed42 复用首轮权重，其余补齐；每组保留全部种子。证据见 `artifacts/optimization/analysis.json`、`family_scores.csv` 与 `history_diagnostics.json`。

## 截断确实严重，但延长未带来稳定收益

L256 使训练/验证患者的 35.5%/36.4% 被截断，仅保留全部训练事件的 53.9%；L512 将截断率降至 8.7%/9.3%，L1024 为 5.1%/5.8%。长历史患者被丢弃的回溯跨度中位约 42 年，这是最早原事件与最早保留事件的日期差，**不代表连续 42 年都有完整观测**。保留事件中约 62% 是观察/检验，诊断仅约 2.6%，密集记录会挤占时间跨度。

长度消融共用完整训练历史拟合的词表、分箱和年龄标准化；患者顺序、标签与既往疾病状态一致。三个长度均采用位置容量 1024、batch16 和相同训练日程，同种子的初始参数一致。原版词表与 batch32 不同，因此截断影响应比较新的 L256 对照。

下表均为同一 365 人验证集；“±”是三种子的**样本标准差**，不是置信区间。每个 checkpoint 仍按验证 mAP 早停。

| 实验组 | mAP 均值 ± SD | macro-AUROC 均值 ± SD | 三种子等权集成 mAP |
| --- | ---: | ---: | ---: |
| 原版 | 0.2237 ± 0.0051 | 0.7387 ± 0.0061 | 0.2462 |
| L256 对照 | 0.2278 ± 0.0047 | 0.7494 ± 0.0022 | 0.2415 |
| L512 | 0.2281 ± 0.0072 | 0.7484 ± 0.0052 | 0.2425 |
| L1024 | 0.2252 ± 0.0099 | 0.7428 ± 0.0047 | 0.2284 |
| L512 无预训练 | 0.2230 ± 0.0113 | 0.7448 ± 0.0149 | 0.2578 |
| L512 均值+末事件池化 | 0.2194 ± 0.0030 | 0.7487 ± 0.0074 | 0.2320 |
| L512 池化+加权 BCE | 0.2147 ± 0.0079 | 0.7458 ± 0.0056 | 0.2191 |
| 完整历史摘要线性 | 0.1792 ± 0.0009 | 0.7327 ± 0.0109 | 0.1906 |

L512 与 L256 的单模型均值仅差 0.000306；集成的差值为 0.0010，患者 bootstrap 95% 区间为 [-0.0154, 0.0324]。长历史子组差值为 -0.0093，亦未显示稳定改善。更多输入不保证小样本模型能有效利用它们。

## 针对性修正及实际结果

摘要保留每个临床 token 的完整历史计数、近两年计数和最近出现时间，全部统计与 scaler 只拟合训练历史。3,816 个摘要特征对应 2,791 人，部分 token 仅覆盖少数患者；标准化后训练/验证最大绝对值约 52.8/305.5，容易放大稀疏噪声。固定裁剪到 [-5,5] 后均分小幅上升，但标准差也增大，尚不能认定稳健收益。

加权 BCE 试图缓解常见目标主导梯度：按训练集 at-risk 正负数计算平方根权重，限制在 [1,8]。理想加权后验满足 `logit(q)=logit(p)+log(w)`，因此 bias 初值加 `log(w)`，推理减去它；偏移随权重保存。常数校正本身不改变逐类 AP/AUROC，也不保证有限样本校准。该组实际均分低于对应池化组，未采用。池化和取消预训练也没有提高单模型均分；取消预训练的三种子集成表现较好，说明个体质量与集成互补性不同。

## 最终选择与不确定性

部署候选按每个**完整三种子集成**的验证 mAP 比较，再比较最佳序列、最佳摘要及固定 50:50 混合。最终是“L512 无预训练 + 摘要 clip5”，六成员各占 1/6，mAP **0.2677**、macro-AUROC **0.7714**。没有挑选最佳种子。

最初曾按单模型均值筛选，观察结果后改为比较实际部署的集成；这是**自适应选择**，并非完全预注册。相对原版三种子集成，mAP 增加 0.0215；500 次配对患者 bootstrap 的 95% 区间为 [-0.0109, 0.0577]，仍跨零。长历史子组点估计反而下降 0.0209，区间 [-0.0630, 0.0428]，不能声称已解决长历史性能问题。

种子 SD 衡量训练波动；患者 bootstrap 同时重采样所有病种和两个模型，衡量固定模型下的患者采样波动。它不消除同一验证集早停、反复实验和自适应选模的偏差。测试标签始终隐藏，不报告本地测试 AUROC/mAP，也不在验证集上重训。

还需注意增益集中：约 **69% 的净mAP增量来自三个相关的前列腺目标**，阳性数为11、8、6，合计只覆盖11名不同验证患者。它们并不是三组独立改善证据，进一步限制了整体提升结论的可靠性。

## Swin 的适用边界

[Swin](https://arxiv.org/abs/2103.14030) 的窗口与分层设计、[Swin UNETR](https://arxiv.org/abs/2201.01266) 的三维 MRI 分割确有参考价值；当前主体是临床事件序列，影像仅覆盖 2 名验证患者，采集日期还需核对。更贴近任务的是 [Hi-BEHRT](https://pmc.ncbi.nlm.nih.gov/articles/PMC7615082/) 的局部片段编码与全局聚合。后续可借鉴这一结构，但论文结果不能当作本题实测收益；题目也禁止使用外部预训练权重。

## 复现与产物

使用项目 `.venv`。长度、摘要及 clip5 缓存通过 `prepare-experiment` 构造；训练入口为 `scripts/run_optimization.py` 的 `length`、`followups`、`refinements` 阶段，已完成运行会核对配置后跳过。完整统计命令：

```powershell
python scripts/summarize_optimization.py --bootstrap 500
python -m ehr_forecast prepare-ensemble --manifest artifacts/optimized_model_bundle/ensemble.json
python -m ehr_forecast predict-ensemble --manifest artifacts/optimized_model_bundle/ensemble.json --output predictions-reproduced.csv
python -m ehr_forecast validate-submission --predictions predictions-reproduced.csv
```

`artifacts/optimized_model_bundle` 保存六份权重、各自编码配方与哈希及推理源码；不包含患者数据。wandb 为离线记录，GitHub、Hugging Face 与线上实验链接仍待正式发布。
