# Five-year first-onset prediction from synthetic EHR

*Technical report — research intern coding test*

## Summary

The task is to predict, for 40 conditions, whether a patient is diagnosed with the condition for the first time in the five years after an anchor date, using only the record before the anchor. The data are Synthea/Coherent synthetic records: 2,791 training, 365 validation and 358 test patients.

The submitted model is deliberately small: three gradient-boosted members on engineered patient-state features, combined per target by greedy selection on rank-transformed out-of-fold scores. All decisions were made on patient-level cross-validation inside the training split; the validation split was used only for monitoring.

| Split | macro AUROC | mAP | random mAP |
| --- | ---: | ---: | ---: |
| train, 5-fold cross-fitted OOF (2,791 patients) | 0.786 | 0.306 | 0.047 |
| official validation (365 patients) | 0.787 | 0.350 (95% bootstrap CI 0.338–0.389) | 0.047 |

Test labels are withheld. Because the test feature distribution matches the training split (adversarial validation AUROC ≈ 0.5), the honest expectation for the test score is the OOF range, 0.30–0.32 mAP; the validation split is an easier draw by about +0.05 for every model we built.

The report is organised around one finding: the 40 targets have three different generative structures, and the design follows from them.

## 1. Representation

**One unit of input is a patient at a landmark year.** For every patient and every second year before the anchor (plus the anchor itself) we compute the state of the record at that time and the label "first diagnosis in the following five years". This person-period construction yields 56,770 rows from 3,514 patients; the anchor rows carry an `is_official` indicator and the time to the end of the record, so the model can tell them apart. Member B uses the anchor rows only.

**Features (2,558 per row, all computed strictly before the landmark).**

| Group | Count | Construction |
| --- | ---: | --- |
| History tokens | 1,800 | For each condition, medication, procedure, immunization, care plan, device, allergy, imaging code and encounter class with ≥ 20 training patients: lifetime count, counts in the last 1 and 5 years, years since the last and since the first occurrence |
| Numeric observations | 413 | For 59 LOINC codes with ≥ 50 training patients: last value, min, max, mean over 5 years, standard deviation, count, linear trend. Raw units, no binning; missing stays missing |
| Prior / active | 83 | Indicator that each of the 40 targets was already diagnosed before the landmark (such patients are not at risk and are scored 0); 43 medications active at the landmark |
| Static | 21 | Age at landmark, sex, race, ethnicity, marital status, encounter rates |
| Genomics | 216 | From the optional `genomics/` files: file present, number of variant alleles and of variant rsIDs, pathogenic and uncertain counts, dosage (0/1/2) for 161 rsIDs, variant counts for 49 genes; DICOM present with a study date on or before the anchor |
| Cost | 25 | From `HEALTHCARE_EXPENSES` / `HEALTHCARE_COVERAGE` in `patients.csv`: the two lifetime totals, pre-anchor spending summed from the event tables (lifetime, last 1 and 5 years), and two-stage residuals: a cross-fitted LightGBM regression predicts the lifetime totals from the pre-anchor record, and the residual isolates spending that the history does not explain |

Vocabularies and support thresholds are fitted on training patients only. Time between events enters through the recency features and through the landmark construction; values are never discretised.

**Modality disclosure.** The README permits any provided modality. The genomics files and the cost fields are both generated by the Coherent pipeline from the patient's complete record, including the five years after the anchor: among training patients without a prior stroke, 50% of those with a DNA file have a stroke in the window versus 2.3% of those without, and the variant count alone separates them with AUROC 0.97; the lifetime coverage field separates future lung-cancer patients with AUROC 0.82 because it includes the treatment. These are label-derived signals, not clinical ones. We report the model with and without them (Section 4) so that the reader can judge either way. Test rows are used only as prediction inputs; the validation split is never trained on; no external data or pretrained weights are used.

## 2. Model and training

**Member A — history generalist.** XGBoost, depth 3, 400 rounds, learning rate 0.03, 30% column sampling, trained on all person-period rows with at-risk masking. Before training each target in each fold, features are ranked by univariate average precision on the fold's at-risk anchor rows and the top 200 are kept together with 44 always-on columns (age, sex, prior flags, landmark indicators). The screening controls the dilution of ~90 positives by 2,500 features.

**Member B — the same evidence, read differently.** LightGBM, 8 leaves, minimum 15 samples per leaf, learning rate 0.03, the same per-target screening, trained on anchor rows only. Rounds follow the measured curves per target group: 100 for accident targets, 150 for chain targets, 350 for terminal targets. Its errors are only partly correlated with A's.

**Member C — dense modality specialist.** LightGBM, 6 leaves, 300 rounds, on age, sex, the 40 prior flags, the genomics features and the cost features, with no history tokens. On its own it reaches OOF mAP 0.260, which shows where the step-change information lives. (Members alone, cross-validated OOF mAP: A 0.295, B 0.283, C 0.260.)

**Assembly.** For each target, Caruana greedy selection with replacement (8 steps) chooses weights over the three members' rank-transformed OOF scores; validation and test scores are mapped through the training score distribution of each member so the blend is a monotone transform of each member's probabilities. Patients already diagnosed before the anchor receive probability 0. The three near-identical lung-cancer targets and the gait / micro-haemorrhage pair are averaged within group.

**Evaluation protocol.** Everything is judged on train out-of-fold predictions with patient-level 5-fold splits. The ensemble weights are additionally cross-fitted: selected on a random half of the OOF rows and evaluated on the other half, averaged over five random halvings, so the reported 0.306 contains no selection optimism. Per-target standard errors are 0.02–0.03 (median 86 positives), and the validation mAP has a bootstrap 95% interval of roughly ±0.04 (365 patients, median 11 positives per target).

**Training curves.** Training and validation log-loss per boosting round for each member and fold, and the per-target metrics of each member and of the assembly, are logged to wandb: [project `ehr-forecast-5y`](https://forge.coreweave.com/wandb/chengxianghuang1122-university-of-british-columbia/ehr-forecast-5y) (runs `memberA_pp_xgb_screen200_ppds_gcr`, `memberB_lgb_official_screen200`, `memberC_history_free_genc2_only`, `assembly_rank_greedy`). The curves show the members are not under-trained: the official-row LightGBM peaks at 200 rounds overall and at 100 rounds on the chain targets, and is slightly worse at 1,200.

**Hyper-parameters** (members): XGBoost `max_depth=3, eta=0.03, n=400, colsample_bytree=0.3, min_child_weight=5, subsample=0.8, lambda=5`; LightGBM `num_leaves=8, min_child_samples=15, learning_rate=0.03, colsample 0.3–0.8 by screened size, subsample=0.8, lambda_l2=5`; member C `num_leaves=6, min_child_samples=10, feature_fraction=0.6, lambda_l2=2, 300 rounds`.

## 3. AI workflow

The project was carried out with two AI coding assistants. An initial pass with Codex implemented the recommended decoder-only Transformer baseline with next-event pre-training and fine-tuning, and its ablations (context length, pre-training, ranking losses). The remainder was done with Claude Code: the data audit, the diagnosis of why scores were low, every subsequent experiment, and this report.

The working method was fixed early and kept: (1) state the problem in terms of the generative process before proposing a model; (2) make every decision on train OOF, never on the validation split, after finding that validation-based comparisons had been reporting improvements that disappeared under cross-validation; (3) run experiments as background GPU/CPU jobs in batches and write each round's results and negative results into a running document before starting the next. The assistant wrote the scripts, launched and monitored the jobs, and drafted the analysis; the author decided which modalities to use and which model to submit.

## 4. Interpretation

**Three generative structures.** Synthea patients are superpositions of independent state machines with constant per-state hazards. This gives the 40 targets three different natures, visible in learning curves measured by training on 25%, 50%, 75% and 100% of the training patients:

| Group | Targets | Mechanism | AP vs. training size | Final OOF AP / AUROC |
| --- | ---: | --- | --- | --- |
| Accident | 15 (sprains, lacerations, fractures, sinusitis, pharyngitis, bronchitis…) | memoryless hazard, no precursor in the record | flat (+0.002 per e-fold of patients) | 0.098 / 0.60, i.e. prevalence and chance |
| Chain | 15 (stroke, CHD, osteoporosis, Alzheimer's, pregnancy, anaemia, polyp…) | determined by the module state at the anchor: precursors, their recency, latest values | rising, +0.03 per e-fold, no plateau | 0.298 / 0.89 |
| Terminal | 10 (lung-cancer triad, MI, CHF, pneumonia, metastasis, prostate…) | every dying patient's last encounter is a death certificate, so the window is the last five years of life and these targets are the cause of death | rising, +0.07 per e-fold | 0.632 / 0.96 |

Two consequences follow. First, 37.5% of the macro average is structurally unpredictable: even perfect prediction of the other 25 targets caps mAP at 0.66 and macro AUROC near 0.83. Second, the chain and terminal targets are sample-limited rather than information-limited; the ensemble's gain over a single model is equivalent to 2.4× more patients, and the only lever left is sample efficiency (landmark rows, screening, small trees).

**Where each target's signal lives.** For every target we computed the best univariate AUROC inside each feature group. Age and era proxies dominate the chain group; genomics carries stroke (0.87), gait abnormality / micro-haemorrhage (0.79) and MI (0.69); the cost residual carries the lung-cancer triad (0.85), metastasis and prostate cancer. The cost signal depends strongly on survival (stroke 0.91 among survivors, 0.71 among the dying), which is why the death probability sits next to it in the features. Within the dying, the models already reach the best univariate separability for cause of death (AUROC 0.87–0.97); the remaining AP gap is the low within-group prevalence (4–19%), not an unused feature. Pneumonia deaths are dementia patients (care-plan recency and MMSE counts, AUROC 0.92).

**Why not a sequence model.** Under the same protocol the Transformer reaches OOF 0.17, a multi-task tabular MLP 0.22, a piecewise-linear-encoded MLP 0.22, a residual network trained on top of the best booster adds nothing (−0.002), and a temporal Transformer whose tokens are the yearly state vectors reaches 0.21. The gap is sample efficiency: the signals are thresholds on sparse counts and a few dense fields, which depth-3 trees capture with a handful of splits, and event order carries no information (the baseline's own ablations on context length and pre-training were flat). A death-gated mixture of experts, a competing-risk softmax, level-2 stacking as the final model, and hierarchical shrinkage of the ensemble weights were all neutral or negative.

**Effect of the optional modalities** (same members and assembly, cross-fitted OOF / validation mAP):

| Inputs | OOF | val |
| --- | ---: | ---: |
| structured tables only | 0.238 | 0.283 |
| + genomics and imaging | 0.267 | 0.316 |
| + cost fields (submitted three-member model) | 0.306 | 0.350 |
| + cost fields, 41-candidate ensemble (not submitted) | 0.316 | 0.368 |

The gains are concentrated where the audit predicted: stroke 0.24 → 0.87, lung-cancer triad 0.30 → 0.84–0.89, MI 0.67 → 0.76. The 41-candidate ensemble we built along the way scores 0.316; we submit the three-member version because it loses 0.01 and can be explained, reproduced and exported in full.

**Validation versus OOF.** The validation split is +0.04 to +0.05 easier than the training OOF for every model from the first baseline to the final one, with the same prevalence and death share; with 365 patients this is sampling, not a modelling effect. Adversarial validation says test resembles train, so the OOF column is the number to expect.
